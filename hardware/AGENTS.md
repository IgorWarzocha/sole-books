# Hardware

- Each item gets its own folder, with the receipt and a short note inside it.
- Use `assets.csv` for durable equipment. Use `expenses.csv` for small consumables.
- Claim hardware when it supports the work. Use 100% business only when personal use is incidental. Otherwise split it.
- A sale of old personal kit is not business income unless that item was already in the business records.
- Use `pipeline.md` for a planned swap before anything is bought or sold.
